# SleepSync · AI 수면 반응 제어 베개

사용자 반응에 따라 수면 환경을 조절하는 AI 스마트 베개 아이디어의 사업계획서와 웹 기반 기술 데모입니다.

## 구성

- `사업계획서_Day8_수면유도베개.pdf`: 사업계획서 완성본
- `portfolio-dashboard/`: 프로젝트 포트폴리오 대시보드
- `sleepsync-demo/`: 수면 준비도 시뮬레이션 및 폐루프 제어 데모

## 데모가 보여주는 것

압력 안정도·미세 움직임·접촉면 온도 신호를 시뮬레이션하고, 최근 30초 특징값을 바탕으로 수면 준비도를 계산합니다. 결과에 따라 사운드·미세진동·온도를 안전 범위에서 조절하며, 준비 상태가 유지되면 자극을 점진적으로 줄입니다.

모든 데이터는 시연용 시뮬레이션이며 의료 진단 또는 치료 결과를 의미하지 않습니다.

## 로컬 실행

정적 HTML/CSS/JavaScript 프로젝트입니다. `portfolio-dashboard/index.html` 또는 `sleepsync-demo/index.html` 파일을 브라우저에서 열면 됩니다.

## 검증

Node.js 내장 테스트 러너로 신호 생성, 특징 처리, 준비도 추론, 안전 제어, KPI 계산, 화면 구조를 검증합니다.
